# ZaloPay 11.17.0 — Full-Stack Static Reverse Engineering (research monorepo)

Reproducible, file-by-file forensic study of the **ZaloPay 11.17.0 XAPK**
(`vn.com.vng.zalopay`, versionCode `1102758`, APKPure mirror) plus a
TypeScript-built 1080p documentary that narrates the methodology and findings.

```
Zalopay-Thanh+toán+&+Tài+chính_11.17.0_APKPure.zip   input artefact (committed)
tools/analyze/                                       analysis pipeline (Python 3.11)
data/*.json                                          machine-readable result set
research/                                            long-form report, EN + VI
video/                                               TypeScript documentary pipeline
```

Everything in `data/` is generated by `tools/analyze/run_all.sh` from the ZIP in
this repository — no network, no emulator, no root, no apksigner/jadx required.

> **Scope & ethics.** This is defensive security research on a publicly
> distributed, Play-signed artefact. The study describes structure, hardening,
> supply-chain provenance and risk classes. It publishes **no** credentials, no
> signing keys, no working exploit, and no step-by-step attack recipe.
> See `research/11-ethics-and-disclosure.md`.

## Quick start

```bash
python3 -m venv .venv && .venv/bin/pip install androguard pyelftools pillow cryptography
bash tools/analyze/run_all.sh          # → data/*.json
cd video && npm install && npm run render   # → video/out/*.mp4
```
